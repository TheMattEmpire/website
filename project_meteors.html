Meteors is an XR/VR Asteroids like taking the original Asteroids game into the 3rd dimension. It is currently a work in progress, focusing on a polished Minimum Viable Product (MVP) in order to get it into the hands of friends and testers to validate the experience.

If validated, I plan to work on extended elements like different front and rear weapons, weapon arrays and limited weapons like Flamethrowers and creating mini black holes. I'm also hoping to add rogue-lite elements such as upgrades to the ship, leaderboards, and challenges to increase value and replayability.

The end goal is to finish the project and learn as much as I can about the full game development pipeline as a solo game developer including polish, marketing, and support. It would be great to make some money, but as this is my first full release I am trying to be realistic.

A key aspect of this project is to try and explore new approaches to XR and VR games and inspire others to make unique games and experiences in a relatively new platform and medium.

Fargrounds is an open source, lightweight, web-based platform for creating and attending multiplayer social interactive experiences without needing to build a game from scratch. People can create and host interactive experiences such as games, events, presentations, virtual spaces, and more that can work on desktop, mobile and eventually virtual reality.

The engine is built from the Hyperfy engine, adding the tools and assets that allow people to easily build environments with others as well allowing users to explore created spaces, set up public events, and purchase assets that work in all compatible experiences such as clothes, accessories, weapons, pets and vehicles all in browser.

No editor or game platform needed. Currently the spaces require self-hosting, but eventually I would like to offer an easy setup within the ecosystem directly much like Roblox and Fortnite UGC.
